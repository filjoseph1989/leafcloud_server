# Database Model: **NPK Predictions**

This document explains the schema and purpose of the `npk_predictions` table.

## 1. Overview
The `npk_predictions` table stores the categorical and numerical predictions generated by the multi-task multimodal AI model (`leafcloud_multimodal_v3_*.keras` or `leafcloud_sensor_boost_*.keras`). The predictions combine image crops with real-time sensor measurements (pH, EC, water temperature) to detect the nutrient profile, detect sensor anomalies, and estimate nutrient concentrations (macro/micro scales).

## 2. Table Schema

| Column | Type | Description |
| :--- | :--- | :--- |
| `id` | Integer | Unique identifier (Primary Key). |
| `daily_reading_id` | Integer | Foreign key linking to the parent `daily_readings` record. |
| `predicted_class` | String | The detected profile name (`Water`, `NPK`, `Micro`, `Mix`). |
| `is_anomaly` | Boolean | True if the AI classification (visual) conflicts with the regression scale estimates (e.g. visual "Water" but high predicted scales). |
| `macro_scale` | Float | Estimated concentration scale for Macro (NPK) nutrients (0.0 to 2.0+). |
| `micro_scale` | Float | Estimated concentration scale for Micro nutrients (0.0 to 2.0+). |
| `predicted_n` | Float | Legacy probability or score for classification (Mix/NPK). |
| `predicted_p` | Float | Legacy probability or score for classification (Micro). |
| `predicted_k` | Float | Legacy probability or score for classification (Water). |
| `confidence_score` | Float | The AI model's classification confidence (0.0 to 1.0) for the argmax class. |
| `prediction_date` | DateTime (TZ) | Timestamp of when the prediction was generated. |

## 3. Relationships
- **Daily Reading**: Each prediction is tied to a specific daily reading in `daily_readings`. This enables ensembled predictions from image crops and telemetry associated with the upload.

## 4. Verification
Check the latest predictions and scales:
```bash
./scripts/run-query.sh "SELECT predicted_class, macro_scale, micro_scale, is_anomaly, confidence_score FROM npk_predictions ORDER BY prediction_date DESC LIMIT 5;"
```
